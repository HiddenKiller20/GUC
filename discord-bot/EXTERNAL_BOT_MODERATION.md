Use /ban_external_bot external_bot:@Bot reason:... to preview the latest observed interaction user. Use confirm:true to ban that bot and the latest observed user at execution time. Requires configured staff access, Manage Roles and Ban Members (or owner), plus GUC bot Ban Members and role hierarchy. Both targets must be server members. No operator is selected manually. Only Discord-provided interaction metadata on visible bot messages received while GUC is online is recorded, starting after this deployment. Private/ephemeral responses, DMs, prefix commands and offline/inaccessible-channel usage cannot be tracked; this is not a guarantee of the latest user overall. No matching record means no bans. User-installed apps absent from the server cannot be banned using this command. Message history is preserved. Failures report partial results. No automatic banning occurs merely from using another bot.
